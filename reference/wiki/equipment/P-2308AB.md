*Motor power of 3.0 kW is very small — purely condensate return service. Type L motor control indicates full SIS instrumentation despite low criticality of fluid.*

## Function

P-2308A/B pump steam condensate from D-2308 (Preflash Column Steam Heater Condensate Drum) to the steam condensate return system. They operate in standby/running configuration. Auto-start is triggered by FY-0502 (flow low signal) when the running pump fails.

## Connections

- **Suction:** D-2308 (Preflash Column Steam Heater Condensate Drum)
- **Discharge common header:** 4"-SCL.5-23-005006-MS11-H (to condensate system 66-0056)
- **Individual discharge lines:** 4"-SCL.5-23-005007-MS11-PP (A), 3"-SCL.5-23-005008-MS11-PP (B)

**FY-0502** provides the key auto-start logic: when discharge flow drops below the low-flow threshold (indicating the running pump has failed), the standby pump receives an automatic start signal. This is the "LOW FLOW START" function visible on the drawing.

## Motor Control Type L

Per Drawing 0001F ("Type L" designation, confirmed by Note 1 on Drawing 0005A):

| Feature | P-2308A/B Status |
|---------|-----------------|
| Auto-start capable | YES — via FY-0502 |
| SIS connected | YES — UC-2301 |
| Running indication | XI (in motor control circuit) |
| Vibration/bearing monitoring | No (small motor, 3 kW) |
| Seal plan | Basic — condensate service |
| TSH bearing temp switches | TSH-23-0508 (P-2308A), TSH-23-0509 (P-2308B) |

*TSH-23-0508 and TSH-23-0509 are the motor bearing temperature switches feeding UC-2301. A high bearing temperature on either pump triggers the SIS Concentration section shutdown.*

## SIS Connection

P-2308A/B are connected to **UC-2301 (Concentration Section SIS)**:
- TSH-23-0508/0509: Bearing temperature high-high — ESD initiators
- FY-23-0502: Auto-start permissive flow signal
- Both pumps STOP on UC-2301 ESD (effect column in C&E table)

See [[instruments/sis-cdn]] for complete UC-2301 pump stop effects.

## Process Engineering Notes

1. **Auto-start criticality**: If both P-2308A/B fail, steam condensate will accumulate in D-2308 and eventually back up into E-2303 tube side, flooding it. This reduces steam heat transfer and causes erratic temperature control at V-2301. LAH-0502 on D-2308 provides advance warning before flooding occurs.

2. **Type L vs. high-priority pumps**: Although Type L is the most instrumented motor control type, P-2308A/B are relatively low-hazard (condensate service, not CHP). The Type L classification is driven by the UC-2301 SIS connection requirement, not by pump criticality in the same sense as P-2302A/B.

3. **Soft starters**: SRT-P2308A/B suggest soft starters are installed to protect the motor on frequent auto-start cycling.

## Process Data Sheet Confirmation (PS-P2308, As-Built Z1)

UOP Project Spec 963766-506 (Sealless Pumps and Drivers data sheet) reveals these are **sealless magnetic-drive pumps**, not conventional mechanically-sealed centrifugals:

| Differential Pressure | 1.53 kg/cm² | PS-P2308 — confirms wiki's 1.53 |

| Rated Power | 2.3 kW overall (0.7 kW hysteresis/mechanical losses; 32.8% overall efficiency) | PS-P2308 |
| Rated Speed | 2950 rpm | PS-P2308 |
| Materials | Casing/impeller killed carbon steel; shaft 316 stainless; **containment shell/stator liner 316 stainless** | PS-P2308 |
| Bearings | SiC (silicon carbide) — internal, product-lubricated | PS-P2308 |
| Min Design Metal Temp | 15°C | PS-P2308 |
| Coupling | Magnetic (no mechanical shaft seal — eliminates seal-failure leak path) | PS-P2308 |
| Motor Note M10 | Minimum autostart static pressure: **2.25 kg/cm²(g)** | PS-P2308 Sheet 7 |

**Sealless design corrects the "Seal plan — Basic" entry in the Motor Control Type L table above** — P-2308A/B have no mechanical seal at all; the magnetic coupling drive eliminates the seal leak path entirely, which is consistent with this being condensate (low-hazard) service where the design choice favors zero-leakage over seal serviceability.
