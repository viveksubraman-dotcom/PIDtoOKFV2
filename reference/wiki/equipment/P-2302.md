# P-2302A/B — Decomposer Circulation Pumps

> ⚠️ **MOST CRITICAL PUMPS IN CDN SECTION.** Loss of both circulation pumps with CHP in the Decomposer requires immediate emergency shutdown. A running decomposer with no recirculation is a thermal runaway condition. See [[hazards/cumene-hydroperoxide]].

**P&ID Reference:** 14780-8120-25-23-0017

---

## Function

P-2302A and P-2302B maintain the **high-recirculation loop** through [[equipment/D-2304]] (Decomposer Drum). The pumps circulate 1,887,481 kg/h of decomposer product, providing a ~30.8:1 dilution ratio that keeps the instantaneous CHP concentration in the reactor below ~2 wt%. This dilution is the **primary inherent safety mechanism** for the entire decomposition process.

Without these pumps running:
- CHP feed must be cut immediately (UXV-1301 closes)
- Decomposer temperature will spike as accumulated CHP decomposes in a shrinking pool
- Potential for thermal runaway and overpressure

**Note on flow discrepancy:** Design capacity 3020 m³/hr × SG 0.996 = ~3,008 tonne/hr, whereas PFD shows S380 at 1,887 tonne/hr. The design capacity represents the pump rated duty (maximum/best efficiency point); normal operation runs at approximately 63% of rated capacity. This is typical for large circulation pumps designed with operational flexibility and to accommodate future plant expansion.

**Motor detail "DG":** Drawing 0017 notes that motor detail "DG" is also acceptable (per STD DWG B-137). DG refers to an alternative connection to the Acid Aromatics Closed Drain Header — both D and DG motor frame configurations are engineered for this service.

Four independent monitoring circuits (A, B, C, D) covering inner and outer seal faces on each side. See [[instruments/pump-seal-plans]] for tag details.

> **Seal failure on P-2302 must not be handled as a simple pump change.** Seal PAL alarm requires immediate investigation. The pump cannot be shut down without first establishing whether the decomposer can be safely maintained with only one circulation pump.

## Safety and Control Integration

| System | Connection | Function |
|--------|-----------|---------|
| UC-2302 (SIS) | Via SIS logic | Decomposer shutdown initiates P-2302 stop; P-2302 failure triggers UXV-1301 close |
| DCS FY-23-1702 | Auto-start permissive | If P-2302A trips, P-2302B auto-starts if in HOA=AUTO |
| DCS Running signal | XI-23-1701A/B | Real-time status to DCS |
| MMS | VE, VI, TE signals | Continuous machine health monitoring |

**Auto-start sequence for P-2302 standby:**
1. P-2302A trips (XI drops)
2. DCS checks P-2302B HOA position
3. If HOA=AUTO → sends start command via FY-23-1702
4. P-2302B starts within seconds — decomposer circulation maintained
5. If P-2302B fails to start → UC-2302 initiates decomposer ESD (UXV-1301 closes)

## Connections

- **Suction:** From [[equipment/E-2307]] (Decomposer Cooler) outlet, S387, ~58°C — cooled recirculation; enters pump from Drawing 0017 (labeled "FROM DECOMPOSER DRUM 23-0013")
- **Discharge:** Returns to [[equipment/D-2304]] (Decomposer Drum) inlet, S380, ~60°C
- **Calorimeter sidestream:** Decomposer recirculation is tapped at E-2307 area and routed to [[equipment/X-2308]] Calorimeters (Drawing 23-0018) and returned — see [[equipment/E-2307]] for line details
- **Seal:** Nitrogen from CHP Nitrogen Header (upstream of UV-1205)
- **Drain:** To Acid Aromatics Closed Drain Header (STD DWG B-137 detail "DG")
