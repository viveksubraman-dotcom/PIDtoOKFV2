# P-2307A/B — Preflash and Flash Columns Overhead Pumps

> ⚠️ CHP-containing overhead service (cumene with trace CHP). DM-CHP seal required. Connect to CHP Closed Drain Header (STD DWG 8-137). See [[hazards/cumene-hydroperoxide]].

*232 m³/hr design covers the ~140,798 kg/h recycle cumene flow (≈166 m³/hr at 0.848 SG) with ~40% design margin. 90 kW motors are the largest in the Concentration sub-section. CHP Closed Drain Header connection required per STD DWG 8-137.*

*The drawing shows "LOW FLOW START" logic on the motor schematic. Per Note 2, motor control is Type B — this auto-start function is DCS-initiated (not hardwired SIS), triggered when the condenser level/flow drops due to running pump failure.*

## Process Role

P-2307A/B pump the condensed cumene overhead from the Preflash and Flash Columns Condenser (E-2301) accumulator sump to:
1. **Recycle Cumene to Feed Wash Column at Oxidation Section** — primary destination (~140,798 kg/h)
2. **Oxidate Long Circulation to Oxidizer No. 2 at Oxidation Section** — secondary destination (long recirculation circuit, 8"-CUL-23-008011)
3. **Return to Condenser E-2301** — via ¾"-CUL-23-008014 (recirculation for level/flow control)

**AI-0801A/B CHP Concentration Analyser**: Monitors CHP in the recycle cumene stream returning to the Oxidation Section. Even trace CHP in recycle cumene could cause issues at the OXI Section feed wash column. The analyzer output (AT-0801) feeds DCS for monitoring and alarm. This is a continuous, online safety-relevant measurement — per "BY ANALYZER VENDOR" note, the entire analyzer package is vendor-supplied.

**Confirmed by Analyzer Process Data Sheet (PS-0003, 2026-06-16)** as a single density transmitter **AT/AY-23-0801** with two simultaneous 4–20 mA outputs (density span 700–1000 kg/m³ + converted CHP wt%, 0–10 wt% span) — these two outputs are what the wiki's "AI-0801A" (CHP) / "AI-0801B" (density) entries represent. Source: 316 SS body, Thermo Fisher Scientific (or equal). ⚠️ Source data sheet warns this is an inferential (density-proxy) measurement — routine lab CHP analysis is required for verification, do not treat as a standalone safety measurement. ## Engineering Notes

### 1. Motor Control Type B — No Hardwired Auto-Start
Drawing 0008B Note 2 states "TYPE B" motor control. Type B schematics (Drawing 0001F) do not include hardwired SIS auto-start circuits. The "LOW FLOW START" function visible on the drawing is a DCS-initiated start — if the running pump trips and flow drops below the FAL-0802 threshold, the DCS generates an alarm and the operator or DCS initiates the standby pump start. This is less rapid than hardwired SIS auto-start (P-2302, P-2308, P-2309) but acceptable for overhead service where a brief loss of flow does not immediately create a safety hazard.

> **Note:** The motor control table in [[instruments/motor-control]] may list P-2307A/B as Type D (auto-start) based on Drawing 0001G. This conflicts with Drawing 0008B Note 2 which explicitly states Type B. Verify motor control type against field-installed hardware.

### 2. Long Circulation Function
The 8"-CUL-23-008011 "OXIDATE LONG CIRCULATION" line provides an alternative path for the overhead cumene back to Oxidizer No. 2. This serves as a cumene recirculation circuit that maintains OXI section flow balance during CDN upsets or when recycle cumene composition is off-spec.

### 3. CHP Analyzer — Plant Safety Gate
The AI-0801A/B analyzer is effectively the "safety gate" for CHP entering the Oxidation Section via recycle cumene. If CHP concentration in recycle cumene rises above safe limits (due to poor separation in V-2301/V-2302), the operator must investigate before CHP contaminates the OXI section.

### 4. 6100mm Minimum (Pump Elevation)
A "6100 MM MIN" note is visible near the pump arrangement — this is likely a minimum NPSH (Net Positive Suction Head) elevation requirement, ensuring the pump suction nozzle is at sufficient height above the condenser sump liquid level to prevent cavitation.
