### SIS Architecture (from Drawing 0001 — Unit Specific Details)
Three Safety Instrumented System logic controllers:
- **UC-2301 (UA-23-2301)**: Concentration Section — controls UXVs on Preflash, Flash, Vacuum, Steam Heater systems
- **UC-2302 (UA-23-2302)**: Decomposition Section — controls UXVs on Decomposer Feed, Decomposer Drum, Dehydrators, Acid Injection; primary safety for decomposer
- **UC-2303 (UA-23-2303)**: Vacuum Producing Equipment — controls P-2316A/B and P-2317A/B

See [[instruments/sis-cdn]] for complete shutdown trigger list.

### Pump Criticality Hierarchy (from Motor Control and Vibration Sheets)
1. **P-2302A/B** (Decomposer Circulation): HV motors, full vibration+bearing temp monitoring, API 11/53A complex dual seal, DCS auto-start (FY-23-1702), UC-2302 SIS connected. **Most critical pumps in CDN.**
2. **P-2308A/B, P-2309A/B** (Condensate Pumps): Type L control (most instrumented), SIS connected to UC-2301, auto-start permissive, TSH temperature protection.
3. **P-2307A/B** (Overhead Pumps): **[CONFLICT]** Motor control table (Drawing 0001G) may list as Type D; Drawing 0008B Note 2 explicitly states **Type B** (DCS-initiated LOW FLOW START, no hardwired SIS auto-start). API 11/53A dual seal. Verify with field hardware.
4. **P-2303A/B** (Decomposer Product): API Plan 2/53A (dead-ended inner seal — unique for CHP product service).
5. **P-2305A–F** (Acid Injection): Type B, no auto-start, no SIS. Manual restart required after trip.

### CHP Nitrogen Header (Critical Utility Segregation)
All nitrogen utility connections **upstream** of UV-1205 (Decomposer Feed) use the **CHP Nitrogen Header** (fed from Oxidation Section). Connections **downstream** of UV-1205 use regular nitrogen header. This segregation ensures CHP-contact nitrogen circuits are never cross-contaminated with instrument air or facility nitrogen. Reference: STD DWG 963766-120-01-A1.

### Sampling Hazard Summary
- **SN-2303** (P&ID 0009, Flash Column Bottoms): CHP line — requires CHP sampling procedure ⚠️
- **SN-2310** (P&ID 0007): Phenol-containing stream (PL line) ⚠️
- **SN-2305** (P&ID 0017): Decomposer Circulation stream — elevated temperature, process hazard
- **SN-2307** (P&ID 0020A): Acid Aromatics Sump — corrosive service

### Control Valve Drain Routing
CDN control valve body drains route to:
- **D-2206** (Oxidation Section sump — CDN and OXI share drain system for some streams)
- **D-2307** (CDN Acid Aromatics Sump)
All drain lines are Closed Drain Header type, routed per line designation tables on each installation detail.
