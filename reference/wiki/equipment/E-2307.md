# E-2307A/B — Decomposer Cooler

> ⚠️ CHP is a peroxide — thermal decomposition risk. See [[hazards/cumene-hydroperoxide]].

**⚠️ CORRECTION (2026-06-07, Drawing 0017):** The Decomposer Cooler is **TWO parallel shells** (E-2307A and E-2307B), not a single unit as previously recorded. Total duty 18.59 MM kcal/h is divided across both shells. Pages created from PFD only referenced E-2307 as a single item.

## Function

E-2307A and E-2307B (in parallel) remove the exothermic heat of CHP decomposition from the Decomposer recirculation stream. This is the **largest single heat duty in the CDN section** and the primary means of temperature control in the Decomposer loop. Temperature is controlled by [[instruments/sis-cdn]] TIC-1302 via split-range cooling water valves across both shells.

## Temperature Control (TIC-1302)

| Element | Description |
|---------|-------------|
| TIC-1302 | Decomposer temperature controller — split-range output to CW control valves |
| TY-1302A | Split-range output A — "HIGH temperature signal CLOSES this valve" |
| TY-1302B | Split-range output B — "LOW temperature signal CLOSES this valve" |
| TV-23-1302A | CW supply control valve — Cv 13,139, 20" body, **fail-open**, dual spring-diaph/piston pneumatic actuator. **Largest control valve in the CDN unit** (PS-0010, 2026-06-16) |
| TV-23-1302B | CW bypass control valve — Cv 1,050, 12" body, fail-close, spring-return piston pneumatic actuator (PS-0010, 2026-06-16) |

**Split-range logic:** TIC-1302 manipulates two CW control valves in opposition to maintain Decomposer at target temperature. One valve handles normal cooling load; the second provides overcooling protection (anti-freeze). When decomposer temperature rises → TIC output increases → cooling CW valve opens further.

## Differential Pressure Monitoring and SIS

| Tag | Type | Description |
|-----|------|-------------|
| PDXT-1701A | DP Transmitter | E-2307A differential pressure |
| PDXT-1702 | DP Transmitter | E-2307B differential pressure |
| PDAL-1701A | DP Alarm Low | E-2307A CW DP low alarm |
| PDAL-1702 | DP Alarm Low | E-2307B CW DP low alarm |
| PDXSLL | SIS DP Low-Low | Loss of cooling water flow → UC-2302 ESD trigger |

**PDXSLL logic:** Low differential pressure across the CW circuit of E-2307 indicates loss of cooling water flow. With Decomposer running (CHP decomposing, exothermic), loss of cooling → uncontrolled temperature rise → potential thermal runaway. PDXSLL feeds UC-2302 for immediate ESD.

Cross-reference with C&E table (Drawing 0002): PDXSHH-1701A/B/C listed as SIL 2, 2oo3 — these are HIGH-HIGH DP on the process shell side (restriction/fouling alarm); PDXSLL is the CW-side low DP safety action. Both are independent ESD paths.

## Acid Analyzer

| Tag | Type | Description |
|-----|------|-------------|
| AT-1701 | Analyzer Transmitter | Sulfuric acid concentration in decomposer recirculation |
| AY-1701 | Analyzer Y-element | Signal conditioning |
| AAL-1701 | Analyzer Alarm Low | Low acid concentration alarm |
| AAH-1701 | Analyzer Alarm High | High acid concentration alarm |

AT-1701 monitors H₂SO₄ concentration in the Decomposer circulation stream to verify that acid injection (P-2305A–F) is maintaining the correct catalyst level. This is a cross-check to the Calorimeter [[equipment/X-2308]] control signal.

**Confirmed by Analyzer Process Data Sheet (PS-0003, 2026-06-16)** as AT/AY-23-1701: colorimetric titration method, range 0–350 wt ppm H₂SO₄, normal 40 ppm but design allows up to **300 wt ppm during start-up** (~7.5× transient — verify against material/corrosion safeguards in startup-deviation HAZOP analysis). Reaction cup material must NOT be PTFE. Stream composition at this point: Phenol 48.94 wt%, Acetone 30.25 wt%, Cumene 12.54 wt%, Dicumylperoxide 3.91 wt%, CHP 1.87 wt%, Water 0.93 wt%. See [[instruments/analyzers-cdn]].

## Safety Significance

> ⚠️ Loss of both E-2307A and E-2307B cooling (PDXSLL trigger) while CHP is in the Decomposer must trigger immediate UC-2302 ESD. Without heat removal, the 18.59 MM kcal/h exotherm from CHP decomposition raises the Decomposer temperature above the safe operating window (target ~72°C, runaway risk above ~90°C).

With E-2307 configured as two parallel shells, loss of ONE shell reduces cooling capacity by 50% — an immediate alarm condition requiring operator response before PDXSLL triggers.
