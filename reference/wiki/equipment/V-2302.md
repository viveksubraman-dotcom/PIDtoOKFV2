# V-2302 — Flash Column

> ⚠️ CHP concentrates in the bottoms of this column to ~80-85 wt% — highest CHP concentration in the Concentration sub-section. Monitor column bottom temperature closely. See [[hazards/cumene-hydroperoxide]].

## Function

Second-stage (deeper) vacuum evaporator in the CDN Concentration sub-section. Further removes residual Cumene from Preflash Column (V-2301) bottoms, producing **concentrated CHP (~80–85 wt%) in the column bottoms** for feed to the Decomposer. Overhead Cumene vapor is condensed and recycled to the Oxidation Section.

## Bottoms Level Control — Split-Range Logic (LY-0801)

A split-range level control scheme manages the Flash Column bottoms:

| Mode | Description |
|------|-------------|
| **Startup position** | LV-0802 operates in startup mode — allows column to fill; LXSHH-0802 bypass active (HXS-0102) |
| **Normal control** | Split-range: LIC-0802 modulates LV-0802 around NLL setpoint |
| **Low-level signal** | Below low level setpoint → closes valve (protects pump from cavitation) |
| **Override (high level)** | HIGH LEVEL → closes valve completely; separate override valve takes over |

Multiple level switches (LY-0801b, c, d) manage transitions between these modes.

## Control Link to Decomposer

A critical process control link connects V-2302 bottoms flow to the Decomposer acid injection system:

```
Flash Column bottoms flow signal (from P&ID 0009)
  → FY-1201B (High Signal Selector)
  → TO MULTIPLIER FY-0012 (P&ID 0012)
  → Decomposer acid injection rate
```

This cascade ensures acid injection rate is proportional to the concentrated CHP feed rate to the Decomposer. More Flash Column bottoms flow = more concentrated CHP = higher acid injection requirement. The High Signal Selector (FY-1201B) picks the higher of the flow-based signal and the calorimeter-based signal — a conservative, fail-safe control design.
