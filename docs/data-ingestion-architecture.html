Data Ingestion & OKF v0.2 Synthesis Architecture

Extracter Agent • Dual-Stream PDF/Drawing Pipeline • Cognitive Precedence Engine • Google ADK & Gemini 2.5 Pro

Dual-Stream PDF/Drawing Ingestion

  • • Stream A (Native Text): Uses pypdf text and layout extraction for structured Data Sheets, SDS documents, and Operating Manuals with intact font tables.
  • • Stream B (Multimodal Drawing): Automatically triggered when is_vector_drawing() detects stroked vector paths (>50 operators) and zero font dictionaries (AutoCAD P&IDs, PFDs).
  • • Gemini Vision Parts: Employs google.genai.types.Part.from_bytes() to perform direct visual inspection of P&ID instrument bubbles, line tags, and stream flow directions.
  • • Zero Ingestion Blindspots: Prevents silent extraction failures where vector-only diagrams yield empty text strings.

Cognitive Precedence Hierarchy

  • • Tier 1 — As-Built Data Sheets: Primary authority for design limits (MAWP, design temp, pump head, impeller diameter, flow rate).
  • • Tier 2 — P&ID Schematics: Definitive authority for piping connectivity, nozzle sizes, instrument tag loops (e.g. 01-FIT-101), and safety valves.
  • • Tier 3 — PFD Heat & Material Balance: Primary reference for normal operating temperatures, pressures, stream compositions, and flow balances.
  • • Tier 4–6 — Manuals, SDS & Standards: Operational limits, startup procedures, chemical hazard classification, and design code compliance.

OKF v0.2 Synthesis & Integrity

  • • Canonical Dual Document: Produces clean YAML frontmatter for machine parsing and structured Markdown body for human engineering review.
  • • _OKFSafeDumper: Custom PyYAML dumper enforcing strict quoted string preservation for engineering tag numbers (preventing octal or scalar coercion).
  • • Rigorous Validation Gate: Every bundle is validated by validate_okf_bundle_tool against Pydantic schema invariants and cross-reference integrity.
  • • Progressive Catalog Index: Maintains okf_index.json as an atomic progressive manifest across single-file and multi-file batch runs.
