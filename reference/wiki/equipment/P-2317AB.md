## Process Role

P-2317A/B supply sealant liquid (process water) to the liquid ring vacuum pumps P-2316A/B. The sealant circuit is:

```
P-2317A/B (sealant pump) → P-2316A/B (liquid ring pump) → D-2316 (separator) 
→ P-2317A/B sealant pump → E-2317A/B (coolers) → back to P-2317A/B suction
```

P-2317A/B must be running **before** P-2316A/B can start — no sealant means no liquid ring, which means no vacuum capability and potential pump mechanical damage. The DCS start sequence enforces this.

## SIS Connection

Both P-2317A/B motors are stopped on UC-2303 ESD. Same DCS-only restart requirement as P-2316A/B (HXS-23-2316). The motor trip logic ensures that if the vacuum system trips, both the vacuum pumps AND sealant pumps stop together, preventing sealant circuit operation without vacuum load.
