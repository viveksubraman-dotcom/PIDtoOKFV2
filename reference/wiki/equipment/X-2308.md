# X-2309A/B — Calorimeters (No. 1 and No. 2)

> ⚠️ CHP is a peroxide — thermal decomposition risk. See [[hazards/cumene-hydroperoxide]].

**TAG RESOLVED (2026-06-07, Drawing 0018):** Correct plant tag is **X-2309A** (Calorimeter No. 1) and **X-2309B** (Calorimeter No. 2). PFD 14780-8120-20-23-0005 incorrectly showed tag X-2308A/B. P&ID Equipment List (Drawing 0000B) and Drawing 0018 both confirm **X-2309**. All wiki pages updated. [Source: Drawing 14780-8120-25-23-0018, Rev Z1 As-Built]

**Technology:** UOP CDN Process — UOP Standard DWG 963766-301-99-A1

## Function

The Calorimeters are **small side-stream test reactors** that continuously measure the decomposition reactivity of the Decomposer recirculation fluid. The calorimeter signal is the **primary input to the acid injection control loop** — it tells the control system how reactive the current decomposer contents are, allowing the acid injection rate ([[equipment/P-2305ABCDEF]]) to be adjusted in real time.

This is a distinguishing feature of the UOP CDN process: calorimeters provide a **predictive, forward-looking reactivity signal** rather than a lagging temperature measurement on the Decomposer itself.

**Operating at 79°C** — slightly above the normal Decomposer loop temperature (72°C), reflecting the exothermic test reaction inside the calorimeter. Very small vessel: 4" SCH 40 pipe section × 470mm long.

**Key design constraints (Drawing 0018 Notes):**
1. All piping and equipment volume subject to **Residence Time Restriction** (Spec 963766-840)
2. Calorimeters must be **located as close as possible** to P-2302A/B suction and discharge piping
3. **Symmetrical piping** for calorimeter loop (both calorimeters must see identical hydraulic conditions)
4. Key interlocked on operating valve set — locked-open valves on inlet side
6. PSV set pressure adjusted for liquid static head (elevated installation)

## Operating Principle

A small sidestream of **Decomposer recirculation** fluid (from [[equipment/E-2307]] area on Drawing 0017) is diverted to each calorimeter. Each calorimeter also receives **acid injection** from [[equipment/P-2305ABCDEF]]. The acid-catalysed decomposition of the residual CHP in the sidestream produces heat; the resulting temperature rise (ΔT) is measured and used as a proxy for current decomposer reactivity.

```
Decomposer Recirculation (Dwg 0017)
   ├─→ X-2309A (Cal No.1): acid injected → ΔT measured → TDXSHH-1801 + TDXAHH-1802
   │                                                              ↘
   │                                                    High Signal Selector
   │                                                              ↗
   └─→ X-2309B (Cal No.2): acid injected → ΔT measured → TDXSHH-1803 + TDXAHH-1804
                ↓
   Higher signal → Ratio Controller XC-1604 → P-2305 stroke adjustment
```

Both calorimeter return flows go back to Decomposer recirculation (Drawing 0017).

## Differential Temperature Instrument Ranges (PS-0034, 2026-06-16) — Closes Numeric-Range Gap

The CDN Temperature Instrument Process Data Sheet (PS-0034) confirms **three distinct ΔT measurements per calorimeter**, resolving the gap previously noted in [[wiki/index]] ("exact numeric setpoints still not sourced from a dedicated instrument data sheet"):

| Tag | Service | Calibrated Range | Reconciles With |
|-----|---------|---------------------|------------------|
| TDXT-23-1801 | Cal No.1 Total System Differential Temperature | 0–40°C | **TDXSHH-1801** (SIS HH trip, UC-2302 ESD) |
| TDT-23-1806 | Cal No.1 Differential Temperature | 0–25°C | TDT-1802 (primary reactivity signal, this page) |
| TDXT-23-1802 | Cal No.1 Inlet Line Differential Temperature | 0–20°C | **TDXAHH-1802** (DCS critical alarm) |
| TDXT-23-1803 | Cal No.2 Total System Differential Temperature | 0–40°C | **TDXSHH-1803** (SIS HH trip, UC-2302 ESD) |
| TDT-23-1809 | Cal No.2 Differential Temperature | 0–25°C | TDT-1804 (primary reactivity signal, this page) |
| TDXT-23-1804 | Cal No.2 Inlet Line Differential Temperature | 0–20°C | **TDXAHH-1804** (DCS critical alarm) |

The **widest span (0–40°C) belongs to the Total System ΔT** feeding the SIS high-high trip — appropriate for the final safety barrier, which must remain valid across the full credible excursion range. The narrower **Calorimeter ΔT (0–25°C)** is the day-to-day reactivity signal used by the acid-injection ratio controller (XC-1604). The **Inlet Line ΔT (0–20°C)** is a DCS-only early-warning signal across the inlet piping, separate from the calorimeter body itself.

> **Residual gap:** PS-0034 confirms instrument *type and calibrated span*, not the *exact numeric trip setpoint* within that span. The precise high-high trip value for TDXSHH-1801/1803 must still be sourced from the DCS/SIS configuration database or C&E engineering package — this is a smaller, more specific residual gap than the one previously recorded. See [[instruments/temperature-instruments-cdn]] for the full register and duplex-RTD inlet/outlet element detail.

## Safety Significance

If a calorimeter reads **too high** → CHP is highly reactive → more acid needed → potential decomposer temperature excursion if not corrected quickly.

If a calorimeter **malfunctions and reads too low** → under-dosing of acid → incomplete decomposition → CHP accumulates → runaway risk when conditions change.

> ⚠️ **Maintenance priority:** Calorimeters must be calibrated regularly. A faulty calorimeter giving low readings is a latent safety risk that may not trigger any alarm until accumulation conditions are reached.
